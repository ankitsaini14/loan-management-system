# Sample salary slip (for testing upload)

Use either file on the borrower **Salary slip** step (PDF, JPG, or PNG, max 5 MB).

| File | Path |
|------|------|
| PDF (recommended) | `samples/sample-salary-slip.pdf` |
| PNG | `samples/sample-salary-slip.png` |

Full path on your Mac:

```text
/Users/khushi/loan-management-system/samples/sample-salary-slip.pdf
```

In the app: **Choose file** → pick that PDF → **Upload slip**.

These are demo-only documents, not real payslips.
